# Valentina Beauty, Split

Statična web stranica (HTML + CSS), bez ovisnosti i bez build koraka.

- `index.html` – stranica (cjenik je u HTML-u, kategorije su `<details>` elementi)
- `style.css` – stilovi
- `images/` – fotografije

Objava: GitHub Pages (Settings > Pages > `main` / root) ili povuci folder na app.netlify.com/drop.
Cijene mijenjaš u `index.html` unutar `<ul class="prices">`.
